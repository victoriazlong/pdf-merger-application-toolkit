# PDF Application Toolkit 

A lightweight Python automation tool designed to streamline document submission workflows by programmatically combining multiple PDF files (e.g., resumes, cover letters, and transcripts) into a single consolidated document.

## Features
- **Sequential Merging:** Combines PDFs in the exact order specified.
- **File Validation:** Checks for missing or misnamed files before attempting merge operations.
- **Lightweight Dependencies:** Uses `pypdf` for efficient file processing without external binary dependencies.
